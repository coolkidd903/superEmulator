ブラウザで、OSを

ブラウザから昔のWindowsやLinuxなどを起動。 BIOS・仮想ディスク・CD-ROM・キーボード・マウスまで、 ひとつの画面にまとめたブラウザ型エミュレーター。

↓ スクロールするとカーソルも時代とともに進化します

できること

「OSを起動するだけ」ではなく、ブラウザ上で仮想PCとして扱えるように設計。

💿

ISOから起動

ISOファイルを読み込んでCD-ROMとして仮想マシンへ接続できます。

💾

仮想HDD

OSから見える仮想ハードディスクを標準搭載。 実機のストレージに近い構成を再現します。

⌨️

F1～F12

画面上部のファンクションキーをクリックして、 ゲストOSへ直接入力できます。

🖱️

マウス操作

v86の画面へマウスを渡してゲストOSを操作できます。

🔍

OS自動判定

ISO内の情報を調べてWindows系などを推定。 必要なら手動選択にも切り替えられます。

🧰

デバッグ機能

詳細ログ、起動進捗、エラー音、Bash入力、 修復スクリプト生成などを搭載。

対応OS

実際に起動できる範囲はv86と各OSの互換性に依存します。

Windows

Windows 95 Windows 98 Windows Me Windows 2000 Windows XP Windows Vista Windows 7 Windows 8 Windows 10 (32bit)

その他

Linux FreeDOS MS-DOS ReactOS Haiku FreeBSD OpenBSD NetBSD Android-x86

Debug Linux

開発用に ./debug-linux/debian.iso を置けば、専用のLinuxデバッグ環境として起動できます。

推奨フォルダ構成

superEmulator/
├─ index.html
├─ libv86.js
├─ v86.wasm
├─ seabios.bin
├─ vgabios.bin
└─ debug-linux/
   └─ debian.iso

GitHub Pagesでは大きなISOをそのまま置けない場合があるため、 その場合はISOアップロード機能を使用できます。
